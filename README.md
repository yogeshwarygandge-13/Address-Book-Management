Address Book Management System

 Project Overview
The Address Book Management System is a menu-driven application developed using C programming. It helps users store, manage, search, and organize contact information efficiently.

Features
- Add Contact: Add new contact details such as name, phone number, and email address.
- Search Contact: Search for contacts using their name or phone number.
- Edit Contact:Update existing contact information.
- Delete Contact:Remove unwanted contacts.
- Display Contacts: View all saved contacts.
- Save Contacts:Store contact details using file handling for future use.

Technologies Used
- C Programming
- Structures
- Pointers
- File Handling
- String Manipulation
- GCC Compiler

 How to Compile and Run

Compile the program:

```bash
gcc *.c -o addressbook
```

Run on Windows:

```bash
addressbook.exe
```

Run on Linux:

```bash
./addressbook
```

Learning Outcomes
- Understanding structures and pointers in C.
- Implementing file handling operations.
- Managing contact information using C.
- Developing menu-driven applications.
- Improving problem-solving skills.

 Conclusion
The Address Book Management System demonstrates practical C programming concepts to build a simple and efficient contact management application.
